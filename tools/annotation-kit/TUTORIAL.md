# CodeGuard 标注与汇总工具 · 零基础教程

这份工具给团队里**没有技术基础**的两位同学使用。你不需要装 Python，不需要联网，不需要懂许可证法律，也不需要看代码仓库。

## 一、你要做什么

1. 打开 `start.bat`（或把 `annotate.html` 拖进 Edge/Chrome）。
2. 选择自己的身份：标注人1 或 标注人2。
3. 对 47 条样本逐条判断：A / B / C。
4. 做完后点“导出我的 CSV”，把 CSV 发给队长。
5. 如果队长让你做试用汇总，再把两份试用表的关键信息录入“试用汇总”页。

你不需要写代码，也不需要填写任何表格格式；工具会自动生成 CSV。

## 二、你不需要知道的事

- 不需要知道 MinHash、LSH、SPDX、Cohen's κ 是什么。
- 不需要自己搜索数据集，不需要打开命令行。
- 不需要计算一致率或 κ；工具会算。
- 不需要把工具里的代码复制到任何地方。

## 三、A/B/C 怎么判断

只看两件事：左边“GPT-4o 回答”和右边“论文配对原文”。

| 选项 | 什么时候选 |
|---|---|
| A | 左边确实抄了右边一段**有表达性的实现**：连续、非平凡，通常一大段函数体/算法步骤被复制。改名、改格式、加注释不影响 A。 |
| B | 两边只是长得像：imports、argparse、异常处理、常量表、短签名、docstring、通用算法骨架。没有实质复制。 |
| C | 看不准、片段太短、原文太通用，或者需要第三人判断。拿不准就选 C。 |

### 三个常见坑

1. **跨项目副本**：右边是论文配对原文，CodeGuard 可能命中另一个仓库里的同一份上游代码。仍然比较左边和右边；如果确实复制，选 A，理由写“命中为同源副本”。
2. **注释/文档字符串**：只复制注释或 docstring，通常 B；注释和实现一起成段复制，按实现选 A。
3. **短片段**：一两行通用写法，B 或 C。不要因为系统显示 S1/S2 就选 A。

## 四、标注步骤

1. 双击 `start.bat`。
2. 在“开始”页点“我是标注人1”或“我是标注人2”。
3. 可选填昵称/代号；不要写学校、学院、教师姓名。
4. 进入“47 条标注”页：
   - 左侧是样本列表；绿色表示已填，红色表示未填。
   - 中间左右两栏是模型回答和原文，黄色高亮只是相同片段定位。
   - 下方三个按钮：A / B / C。
   - 按键盘 A/B/C 也可以；选完会自动跳下一条。
5. 如果选 B 或 C，请在“一句话理由”里写原因。
6. 进度会自动保存在浏览器里。每完成 10–20 条，建议点一次“导出我的 CSV”备份。
7. 47 条全部完成后，再导出一次，并把 CSV 发给队长。

## 五、只能交什么，不能交什么

- **可以交给队长**：导出的 CSV，例如 `model-leak-20261021-标注表-标注人1.csv`。
- **不要转发**：`annotate.html`、截图里的第三方原文、GPT-4o 回答、论文配对原文。
- 原因：工具里含 LiCoEval 数据集原文，许可证是 AGPL-3.0-or-later，只允许队内本地标注使用。

## 六、试用汇总怎么做

1. 队长会把 `trial/` 里的两份试用表交给两位非项目成员。
2. 两位成员本人填写并签名/写日期。
3. 回收后，打开工具，进入“试用汇总”页。
4. 把两份原始表里的信息**照抄**进去：昵称、背景、环境、完成任务数、耗时、主要卡点、是否愿意继续使用、最有价值反馈。
5. 勾选“我确认下面所有字段均照抄自试用者本人填写的原始表”。
6. 点“生成试用汇总”，再下载 Markdown 发给队长。

不要补脑，不要把负面反馈删掉，不要替试用者编原话。

## 七、标注汇总怎么做（队长或第三人）

1. 收齐两份 CSV。
2. 打开工具，进入“标注汇总”页。
3. 分别选择“标注人1 CSV”和“标注人2 CSV”，点“计算汇总”。
4. 如果有分歧样本，第三人逐条选择复核结论，并写理由。
5. 点“复制报告句子”或“下载汇总 Markdown”。
6. 队长把汇总写进技术报告 §5，并把两份原始 CSV、复核结果放进佐证包。

## 八、常见问题

**Q：我不会看代码怎么办？**
A：看黄色高亮和左右两段是否“同一实现被搬过去”。如果只是一堆 import 或一个很普通的循环，选 B；拿不准选 C。

**Q：能不能全选 A 交差？**
A：不能。这是赛事要求的“双人独立标注”，全选 A 会被队长用脚本发现，也会让评委追问。

**Q：能不能看队友的答案？**
A：不能。两份 CSV 必须各自完成。

**Q：浏览器说无法保存？**
A：用 Edge 或 Chrome；不要用微信内置浏览器。每完成 10 条导出一次 CSV。

**Q：我中途关掉了页面，记录会丢吗？**
A：通常不会，进度存在浏览器本地。但如果你清缓存或换电脑，会丢。所以做完一部分就导出一次。

**Q：工具会不会自动帮我判断？**
A：不会。工具只准备证据、保存你点的结果、做统计汇总。A/B/C 必须你本人点。

## 九、最低完成标准

- 标注人：47/47 条都有 A/B/C；B/C 有理由；导出 CSV。
- 试用汇总：两份原始表齐全；汇总字段照抄；勾选确认。
- 第三人：所有分歧样本有复核结论，或明确写“待复核”。
